Download **`ChestCounter.exe`** below and run it — nothing to install and no extra dependencies needed.

> **Turn on replays in Fortnite first:** *Settings → Game → Replays → Record Replays: **On***. The app only reads your saved replay files in read-only mode — 100% Easy Anti-Cheat safe.

**What's new in 1.9.0**
- **Discord-Style Startup Updater Box:** Shows a dark rounded splash window with a spinning chest logo and live download progress bar whenever checking for or installing updates.
- **Fixed Discord Rich Presence:** Connects reliably to Discord Desktop (`discord-ipc-0`) out of the box to display your live session chest count, total chests, treasures, and elapsed timer.
- **Treasure Hours Schedule & Reminders:** Live 1-second countdown card on Home in your local timezone, 5-minute + live in-app & Windows pop-up notifications, and a day-of reminder when you boot up Fortnite.
- **Zap Mode (Storage Saver):** Automatically deletes counted `UnsavedReplay-*.replay` files to save disk space (toggle in **Settings**).
- **Fixed Update Check Handling:** No longer reports `"GitHub cannot be reached"` when no release is published yet.

*Windows may show "Windows protected your PC" because the exe is unsigned — click **More info → Run anyway**.*
