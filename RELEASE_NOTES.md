Download **`ChestCounter.exe`** below and run it — nothing to install and no extra dependencies needed.

> **Turn on replays in Fortnite first:** *Settings → Game → Replays → Record Replays: **On***. The app only reads your saved replay files in read-only mode — 100% Easy Anti-Cheat safe.

**What's new in 2.0.0**
- **Pure Native Windows Desktop UI (No WebView2):** Completely replaced the WebView2/Chromium web app with a fast, lightweight native dark-mode desktop interface — instant startup, tiny memory footprint, zero background Edge processes, and a single self-contained `.exe`.
- **Discord-Style Startup Updater Box:** Spinning chest logo with a live download progress bar whenever checking for or installing updates.
- **Treasure Hours Schedule & Reminders:** Live countdown in your local timezone, 5-minute + live in-app & Windows pop-up notifications, and a day-of reminder when you boot up Fortnite.
- **Discord Rich Presence:** Shows your live session chest count, total chests, treasures, and elapsed timer on Discord automatically.
- **Zap Mode (Storage Saver):** Optional toggle in **Settings** to delete counted `UnsavedReplay-*.replay` files and save disk space.
